# LLM-Reward-Shaping-DQN-IDS

LLM-Guided Reward Shaping for Deep Reinforcement Learning-Based Network Anomaly Detection.

## Overview

This project investigates the use of Large Language Models (LLMs) as semantic security critics to improve Deep Reinforcement Learning (DRL) for network anomaly detection.

Traditional DQN-based intrusion detection suffers from sparse environmental rewards because malicious network events are relatively rare. This project introduces an LLM-guided Potential-Based Reward Shaping (PBRS) framework that generates dense semantic reward signals while preserving the optimal reinforcement learning policy.

The proposed framework is evaluated on the CICIDS2017 intrusion detection dataset and compared with a conventional DQN baseline.

---

## Research Objectives

- Develop a DQN agent for network anomaly detection.
- Integrate an LLM Security Critic for semantic traffic evaluation.
- Generate Potential-Based Reward Shaping (PBRS) rewards.
- Improve learning speed under sparse-reward conditions.
- Compare against a conventional DQN baseline.

## Methodology

The proposed framework combines:

- Deep Q-Network (DQN)
- Experience Replay
- Bellman Temporal-Difference Learning
- Potential-Based Reward Shaping (PBRS)
- LLM Security Critic
- Prompt Engineering

The total reward used for training is

$$
R_{total}=R_{env}+F(s,s')
$$

where

$$
F(s,s')=\gamma\Phi(s')-\Phi(s)
$$

is the semantic shaping reward generated by the LLM Security Critic through Potential-Based Reward Shaping (PBRS).

The Bellman target used to update the DQN is

$$
y=R_{total}+\gamma\max_{a'}Q(s',a')
$$

where:

- $R_{env}$ is the environmental reward generated from the hidden ground-truth labels.
- $F(s,s')$ is the LLM-generated shaping reward.
- $\Phi(s)$ is the semantic potential assigned to state $s$.
- $\gamma$ is the reward discount factor.
- $Q(s',a')$ is the estimated action-value of taking action $a'$ in the next state $s'$.

is the semantic shaping reward generated from the LLM.
